# IAS2 Commerce

Static website with customer and admin flows for a simple online store.

## Open

Open `index.html` in a browser.

## Demo Accounts

- Admin: `admin@ias2.test` / `admin123`
- User: `user@ias2.test` / `user123`

## Included

- Login and registration
- Shopping cart
- Mock payment checkout
- Admin CRUD for users, items, and orders
- Local browser storage for demo data

This is a front-end demo only. Passwords and payment references are stored locally in the browser and should not be used as-is for a real production system.
